    How it works

    Verify once. Enforce every time. Revoke without asking.

    GLEIF's August 2026 discussion paper proposes an Agent Mandate Credential and notes that on open rails no single intermediary holds its state. Writ puts that state in a NEAR contract.

    Credential

    Who authorized this agent

    A vLEI-shaped chain: root → QVI → legal entity → employee → agent. A verifier checks it once off-chain with keripy and signs an attestation. The company's LEI stays a salted commitment on-chain until a public, delayed disclosure.

    Key

    What the agent can touch

    The agent's KERI key is also a NEAR function-call key, restricted by the protocol to one method. The contract adds and deletes it on its own account, so revoked means the key no longer exists.

    Contract

    What each payment must pass

    Permitted payee, unpaid invoice, per-payment cap, hash-chain budget, daily rate, expiry. Rejections are normal transactions with a hash and an event, and three in a row delete the key.
